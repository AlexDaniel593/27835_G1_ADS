# 27835_G1_ADS

Este directorio corresponde a la **Biblioteca de Soporte** del proyecto **Mueblerix**, donde se almacenan los **Elementos de Configuración del Software (ECS) aprobados en versiones intermedias**, que sirven como respaldo, referencia histórica y soporte para el desarrollo, validación y control de cambios del proyecto.

---

## Estructura de la Biblioteca de Soporte

| Código | Carpeta | Descripción | Fecha de Última Actualización | Responsables |
|-------|--------|-------------|-------------------------------|--------------|
| BS-01 | 1. ELICITACIÓN | Contiene versiones aprobadas de documentos de requisitos utilizadas como soporte y referencia durante el proyecto. | 27/01/2026 | Kevin Amaguaña, Jairo Bonilla, Daniel Guamán, Reishel Tipán |
| BS-02 | 2. PERFIL DE PROYECTO | Incluye versiones de soporte del perfil del proyecto, empleadas para seguimiento y control. | 27/01/2026 | Kevin Amaguaña, Jairo Bonilla, Daniel Guamán, Reishel Tipán |
| BS-03 | 3. DISEÑOS | Almacena versiones de diseño que sirven como respaldo previo a su liberación en la Biblioteca Maestra. | 27/01/2026 | Kevin Amaguaña, Jairo Bonilla, Daniel Guamán, Reishel Tipán |
| BS-04 | 4. MANUALES | Contiene versiones de soporte de los manuales del sistema, utilizadas durante revisiones y validaciones. | 27/01/2026 | Kevin Amaguaña, Jairo Bonilla, Daniel Guamán, Reishel Tipán |

---

## Observaciones

- La **Biblioteca de Soporte** almacena documentación **aprobada pero no liberada oficialmente**.
- Sirve como respaldo ante auditorías, revisiones o retrabajos.
- Los documentos aquí contenidos pueden evolucionar antes de ser promovidos a la **Biblioteca Maestra**.
- Cualquier modificación debe registrarse respetando el control de configuración del proyecto.
- Esta biblioteca forma parte del esquema formal de gestión de configuración del proyecto **27835_G1_ADS**.
