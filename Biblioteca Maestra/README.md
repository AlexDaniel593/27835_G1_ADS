# 27835_G1_ADS

Este directorio corresponde a la **Biblioteca Maestra** del proyecto **Mueblerix**, donde se almacenan los **Elementos de Configuración del Software (ECS) oficialmente aprobados**, consolidados y listos para su entrega, auditoría o liberación, de acuerdo con el control de configuración del proyecto.

| BM-02 | 2. PERFIL DE PROYECTO | Incluye la documentación oficial del perfil del proyecto, aprobada para referencia y control. | 27/01/2026 | Kevin Amaguaña, Jairo Bonilla, Daniel Guamán, Reishel Tipán |
| BM-03 | 3. DISEÑOS | Almacena los diagramas y documentos de diseño validados y aprobados del sistema Mueblerix. | 27/01/2026 | Kevin Amaguaña, Jairo Bonilla, Daniel Guamán, Reishel Tipán |
| BM-04 | 4. MANUALES | Contiene los manuales oficiales del sistema (Manual de Usuario y Guía de Instalación) aprobados para uso y distribución. | 27/01/2026 | Kevin Amaguaña, Jairo Bonilla, Daniel Guamán, Reishel Tipán |

## Observaciones

- La **Biblioteca Maestra** contiene únicamente documentación **aprobada y liberada**.
- Los documentos aquí almacenados constituyen la **referencia oficial del proyecto**.
- Cualquier modificación a estos documentos requiere la creación de una nueva versión y su correspondiente aprobación.
- Esta biblioteca forma parte del **control formal de configuración** del proyecto **27835_G1_ADS**.
