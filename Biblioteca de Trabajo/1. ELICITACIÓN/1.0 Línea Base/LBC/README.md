# Línea Base LBC - Implementación

Aquí se encuentra todo el código fuente y scripts del proyecto Mueblerix, organizado para el desarrollo y pruebas.

## Contenido principal:
- Código fuente frontend (React + Vite) y backend (Spring Boot)
- Configuraciones y archivos del proyecto (package.json, eslint.config.js, pom.xml, etc.)
- Base de datos y scripts SQL
- Recursos públicos y componentes React
- Servicios REST y controladores para la lógica de la aplicación
- Estructura de entidades JPA y repositorios

## Estructura del código:
- **Frontend**: Aplicación React con Vite, componentes UI y gestión de estado
- **Backend**: API REST con Spring Boot, servicios y acceso a datos
